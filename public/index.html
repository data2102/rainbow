  • ANNOUNCE SERVER 해제 — 꺼두세요. 켜두면 방이 모두의 JOIN GAME 목록에 떠서, 런쳐를 거치지 않고도 아무나 들어옵니다. 끄면 주소를 아는 사람만 들어올 수 있고, 그 주소는 사이트에서 같은 방에 들어와 있는 사람에게만 보입니다
  • INTERNET / LAN LAN — Radmin 이 랜처럼 이어주므로 LAN 이 더 빠릅니다. 이 값은 게임이 응답을 얼마나 참고 기다릴지를 정합니다 — INTERNET 은 느린 회선을 가정해 한참 기다립니다.
  • INTERNET / LAN INTERNET — 공인 IP 로 곧장 붙는 방식이라 INTERNET 이 맞습니다.
  • BEHIND FIREWALL NO — YES 로 두면 느려집니다. 대신 아래 포트를 열어주세요
  • JOIN PORT 2346 · ANNOUNCE PORT 2347 · INFO PORT 2348 — 기본값 그대로
