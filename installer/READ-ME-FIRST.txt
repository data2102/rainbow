----------------------------------------------------------------
 1.  installer\payload\ 안의 세 폴더를 채웁니다
----------------------------------------------------------------

  [ installer\payload\game\ ]   게임 파일 3개를 그대로 넣기

        r6setup101a.part01.exe
        r6setup101a.part02.rar
        r6setup101a.part03.rar

        - 세 개가 전부 있어야 합니다
        - 이름을 바꾸지 마세요 (서로를 이름으로 찾습니다)


  [ installer\payload\skin\ ]   레나스킨_V2 "안의 내용물"을 넣기

        레나스킨_V2 폴더를 열고 -> Ctrl+A -> Ctrl+C ->
        payload\skin 에 들어와서 Ctrl+V

        맞는 모양:                    틀린 모양:
          payload\skin\character\       payload\skin\레나스킨_V2\character\
          payload\skin\save\            (폴더가 한 겹 더 있으면 안 됩니다)
          payload\skin\sound\
          payload\skin\texture\


  [ installer\payload\extra\ ]  비워두어도 됩니다

        게임 폴더 맨 위에 얹어야 하는 파일이 있으면 넣는 자리입니다.
        지금 게임이 잘 도는 PC 의 게임 폴더에 아래 같은 것이 있다면
        여기에 넣어주세요. 안 넣으면 받는 사람 화면이 다를 수 있습니다.

              D3D8.dll  D3D9.dll  D3DImm.dll
              dgVoodoo.conf  dgVoodooCpl.exe
              3Dfx\  MS\  Doc\  Cpl\
              DDrawCompat-RainbowSix.ini
              sherman.kmp  Sherman.txt  ShermanScreenShot1.bmp
              MANUAL JOIN.bmp

        각 폴더 안의 _README.txt 에 더 자세히 적어두었습니다.


----------------------------------------------------------------
 2.  BUILD.bat 을 더블클릭합니다
----------------------------------------------------------------

  검은 창이 뜹니다. 몇 분 걸립니다.
  창이 멈춘 것처럼 보여도 도는 중입니다. 기다리세요.

  처음 한 번은 "Inno Setup 을 받아서 깔까요? (Y/N)" 하고 묻습니다.
  Y 를 누르면 알아서 받아서 깝니다. 5MB 짜리 무료 프로그램이고,
  설치 파일을 만드는 데만 쓰입니다. 이때 윈도우가 권한을 물으면
  '예' 를 눌러주세요.

  다 되면 여기에 파일이 생깁니다:

        installer\output\R6ClanSetup.exe        (약 75MB)

  ★ 이 파일 하나를 클랜원들에게 나눠주면 됩니다. ★


================================================================
 클랜원이 R6ClanSetup.exe 를 받으면
================================================================

  더블클릭 -> 다음 -> 다음 -> 설치.  그게 전부입니다.

  설치 파일이 알아서 하는 것:

    1. 게임 압축 풀기
    2. regsetup.exe 실행       (게임 경로를 윈도우에 등록)
    3. HonestEngine 창 띄우기  <- [Install] 을 한 번 눌러야 합니다
    4. 레나스킨 V2 를 data 폴더에 덮어쓰기
    5. 클랜 접속 설정          (사이트 버튼 . 런쳐 . 방화벽)

  받는 사람에게 남는 손길은 두 가지뿐입니다.

    - 설치 도중 HonestEngine 창의 [Install] 클릭 한 번
      (창짜리 프로그램이라 대신 눌러줄 수가 없습니다.
       무엇을 눌러야 하는지 안내문이 먼저 뜹니다)

    - 게임 안의 MULTIPLAYER OPTIONS 설정
      (게임 내부 설정이라 밖에서 건드릴 수 없습니다.
       사이트 런쳐 탭에 무엇을 맞추는지 적혀 있습니다)
