# 레인보우 식스 통합 설치 파일 만들기

받는 사람이 **한 번 받아서 한 번 실행하면 끝**나는 설치 파일(`R6ClanSetup.exe`)을 만듭니다.

```
지금            게임 설치 → 패치 → 맵 복사 → 스킨 복사 → 사이트에서 파일 3개 받기 → 각각 실행
이걸로 바꾸면   R6ClanSetup.exe  더블클릭
```

---

## 만드는 순서 (4단계)

### 1단계 · Inno Setup 을 깝니다 (한 번만)

https://jrsoftware.org/isdl.php 에서 **innosetup-6.x.x.exe** 를 받아 설치하세요. 무료입니다.
설치 중 물어보는 건 전부 기본값으로 두고 넘어가면 됩니다.

> 설치 파일을 **만드는 사람**만 필요합니다. 받아서 쓰는 사람은 깔 필요 없습니다.

### 2단계 · 완성된 게임 폴더를 통째로 복사해 넣습니다

1. 게임이 깔린 폴더를 엽니다
   보통 `C:\Program Files (x86)\Red Storm Entertainment\Tom Clancy's Rainbow Six`
2. `Ctrl+A` (전체 선택) → `Ctrl+C` (복사)
3. 이 저장소의 `installer\payload\game\` 폴더에 들어가 `Ctrl+V` (붙여넣기)

넣고 나면 이렇게 보여야 합니다:

```
installer\payload\game\RainbowSix.exe      ← 이게 바로 보여야 맞습니다
installer\payload\game\data\
installer\payload\game\...
```

`payload\game\Tom Clancy's Rainbow Six\RainbowSix.exe` 처럼 **폴더가 한 겹 더 있으면 안 됩니다.**

> 이미 패치·맵·스킨·타겟·사운드가 다 적용된 폴더를 넣는 것이 핵심입니다.
> 설치 파일이 그 순서를 흉내 낼 필요가 없어집니다.

### 3단계 · `build.bat` 을 더블클릭합니다

검은 창이 뜨고 압축이 진행됩니다. 게임 폴더가 크면 **몇 분 걸립니다.**
`Done.` 이 뜨면 끝입니다.

### 4단계 · 결과물을 확인합니다

```
installer\output\R6ClanSetup.exe
```

이 파일 하나를 나눠주면 됩니다.

## 이 설치 파일이 하는 일

| | 하는 일 |
|---|---|
| 게임 본체 | 완성된 게임 폴더를 그대로 풀어놓습니다 |
| 게임 실행 등록 | 사이트의 버튼이 게임을 바로 켤 수 있게 `r6clan://` 을 등록합니다 |
| 관리자 권한 | 게임이 항상 관리자 권한으로 켜지게 해둡니다 |
| 런쳐 | `C:\R6Clan\` 에 `r6launch.bat` 등 4개를 넣습니다 |
| 경로 맞추기 | 런쳐 파일 안의 게임 경로를 **실제 설치한 위치로 고쳐 씁니다** |
| 방화벽 | UDP 2346~2348 과 게임 프로그램을 윈도우 방화벽에서 열어줍니다 |

즉 지금 사이트 런쳐 탭의 **필수사항 1·2·3 을 전부 대신합니다.**

받는 사람이 여전히 직접 해야 하는 건 **게임 안의 MULTIPLAYER OPTIONS 설정(4번)** 하나뿐입니다.
게임 설정 파일 형식이라 밖에서 건드리기 어렵습니다.

## 자주 막히는 곳

**`[X] Inno Setup was not found.` 라고 나옵니다**
1단계를 안 하셨거나, 기본 위치가 아닌 곳에 까셨습니다.
`build.bat` 을 메모장으로 열어 위쪽 경로 목록에 실제 설치 경로를 추가하세요.

**`[!] game : payload\game\RainbowSix.exe not found` 라고 나옵니다**
2단계에서 폴더가 한 겹 더 들어갔을 가능성이 큽니다.
`payload\game\` 을 열었을 때 `RainbowSix.exe` 가 바로 보여야 합니다.

이 상태로도 빌드는 됩니다. 다만 **게임 없이 클랜 설정만 하는 설치 파일**이 나옵니다.
(이미 게임이 깔린 사람에게 주기엔 오히려 이게 편합니다 — 용량이 몇 MB밖에 안 됩니다.)

**만든 파일이 너무 커서 못 올립니다**
저장소나 Vercel 에는 올릴 수 없습니다. 구글 드라이브 같은 곳에 올리고
사이트 런쳐 탭에는 그 링크만 걸어주세요.

**백신이 잡습니다**
방화벽 규칙을 추가하고 프로그램을 등록하는 동작 때문입니다.
남에게 주기 전에 게임이 없는 다른 PC에서 한 번 실행해 확인해보세요.

## 주의

- `payload\` 안의 내용은 **저장소에 올라가지 않습니다** (`.gitignore` 로 막아둠).
  이 저장소는 공개(public)이라 게임 파일이 올라가면 안 됩니다.
- `output\R6ClanSetup.exe` 도 같은 이유로 올라가지 않습니다.
- 남에게 주기 전에 **게임이 깔려 있지 않은 PC 에서 한 번 시험해보세요.**
  이미 게임이 있는 PC에서는 문제가 안 드러납니다.

## 파일 설명

| 파일 | 무엇 |
|---|---|
| `R6ClanSetup.iss` | 설치 파일 설계도. 동작을 바꾸려면 이걸 고칩니다 |
| `build.bat` | 더블클릭하면 설계도대로 설치 파일을 만듭니다 |
| `info-before.txt` | 설치 첫 화면에 뜨는 안내문 |
| `payload/game/` | 완성된 게임 폴더를 넣는 자리 (비어 있음) |
| `output/` | 만들어진 설치 파일이 나오는 자리 |
