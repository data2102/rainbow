서로를 어떻게 찾는가 — 접속 방식 두 가지

방장이 실행하면 참가자들이 방장의 주소로 곧장 붙습니다. 그 주소를 무엇으로 할지 두 가지 중에 고릅니다. 위쪽 내 접속 주소 줄의 "방식 바꾸기"에서 언제든 바꿀 수 있습니다.

  • Radmin VPN 기본 — 모두 Radmin 에 모여서 그 안의 주소(26.…)로 붙습니다. 공유기를 손댈 필요가 없습니다. 각자 자기 주소를 한 번만 적어두면 됩니다.
  • 공인 IP · 자동 나중에 — Radmin 없이 곧장 붙습니다. 적을 것도 켤 것도 없지만, 방장 쪽 공유기에 UDP 2346 이 열려 있어야 합니다(r6upnp.bat). 공유기가 UPnP 에 답하지 않으면 손으로 열어야 하고, 통신사가 공인 IP 를 안 주는 회선(CGNAT)은 아예 안 됩니다.

방식은 사람마다 따로입니다. 실제로 쓰이는 것은 그 방 방장의 방식뿐이라, 방 안에서 서로 달라도 됩니다. 참가자는 방에 걸린 주소로 붙기만 합니다.

처음 한 번만 — 게임 실행 등록하기

아래 파일을 받아 한 번만 실행하면, 런쳐의 실행하기·조인하기 버튼이 바로 레인보우식스를 켭니다. 등록하지 않아도 방과 대화는 그대로 쓸 수 있고, 접속 주소는 복사됩니다.

  1. r6clan.reg 내려받기 — 메모장으로 열어보시면 내용이 다 보입니다. 게임 경로 두 줄이 전부입니다.
  2. 파일을 두 번 눌러 실행 → "예" → "확인"
  3. 게임이 다른 곳에 깔려 있으면, 메모장으로 열어 경로만 고친 뒤 실행하세요.

이 파일은 두 가지를 적어둡니다 — 게임을 켜는 r6clan:// 약속과, 레인보우식스를 늘 관리자 권한으로 실행하라는 표시입니다. (게임 속성 › 호환성의 "관리자 권한으로 이 프로그램 실행" 체크와 같은 것)

기본 경로는 C:\Program Files (x86)\Red Storm Entertainment\Tom Clancy's Rainbow Six\RainbowSix.exe 입니다. 게임이 켜질 때 창이 두 번 뜹니다 — 브라우저가 "이 사이트가 앱을 열려고 합니다"(허용), 이어서 윈도우가 "이 앱이 디바이스를 변경하도록 허용하시겠어요?"(예). 관리자 권한으로 켜기 때문에 윈도우 쪽은 매번 묻습니다.

더 나아가 — 로비까지 한 번에 (선택)

위 기본 등록은 게임을 켜주는 데까지입니다. 여기까지 하면 메인 메뉴를 거치지 않고 로비로 곧장 들어갑니다. 안 해도 게임은 켜집니다.

  1. C:\R6Clan\ 폴더를 만들고 r6launch.bat 를 그 안에 넣기
  2. r6clan-auto.reg 를 받아 실행 → "예" → "확인"

배치 파일이 하는 일은 게임에 주소를 넘겨 켜는 것뿐입니다. 메모장으로 열면 전부 보입니다.

  • 방장 RainbowSix.exe -server 2346
  • 참가자 RainbowSix.exe -client 방장IP 2346

설명서에는 없는 스위치입니다. 예전 Voobly 설치 파일 안에 적혀 있던 것을 찾아낸 것이고, 실제로 되는 것을 확인했습니다. 메뉴를 하나도 거치지 않으므로 화면 크기가 사람마다 달라도 상관없습니다.

게임이 다른 곳에 깔려 있으면 r6launch.bat 을 메모장으로 열어 GAME 경로만 고치면 됩니다. 기본 등록으로 되돌리려면 r6clan.reg 를 다시 실행하세요.

참가자가 Multiplayer Connecting 에서 멈출 때

게임이 켜지고 Multiplayer Connecting 이 뜬 채로 멎어 있다면, 게임을 켜는 데까지는 다 맞은 것입니다. 두드리고는 있는데 방장 쪽까지 닿지 않는 상태이고, Radmin 방식에서는 볼 곳이 셋뿐입니다.

  1. 양쪽 다 Radmin VPN 에 들어와 있나요? 위 Radmin VPN 줄의 네트워크에 둘 다 접속해 있어야 합니다
  2. 방장의 주소가 맞나요? 방장이 위쪽 내 접속 주소에 적어둔 값이 지금 Radmin 창에 보이는 값과 같아야 합니다. 컴퓨터를 바꾸거나 Radmin 을 다시 깔면 달라집니다
  3. r6firewall.bat 을 둘 다 돌렸나요? 안 열려 있으면 게임이 포트마다 시간초과를 기다렸다 넘어가느라 느립니다

그래도 안 되면 참가자 PC 의 C:\R6Clan\r6launch.log 를 보세요. IP 줄에 방장 주소가 제대로 들어갔는지, RESULT 가 무엇인지 적혀 있습니다.

참가자가 Multiplayer Connecting 에서 멈출 때

게임이 켜지고 Multiplayer Connecting 이 뜬 채로 멎어 있다면, 참가자 쪽은 다 맞은 것입니다. 두드리고는 있는데 방장 쪽에서 받아주지 않는 상태입니다. 볼 곳은 방장의 공유기 하나뿐입니다.

  1. 방장이 r6upnp.bat 을 관리자 권한으로 실행합니다
  2. 화면 끝의 router sees you as 주소를 확인합니다
  3. 그 주소가 위쪽 내 접속 주소 와 같아야 합니다

두 주소가 다르면 공유기가 두 겹으로 물려 있는 것입니다(통신사 장비 + 내 공유기). 안쪽 공유기만 열려서 바깥에서는 여전히 닿지 않습니다. 바깥 장비까지 열거나, 접속 방식을 Radmin 으로 바꿔주세요.

[X] The router did not answer UPnP 가 뜨면 공유기가 UPnP 요청에 답하지 않은 것입니다. 이유는 둘 중 하나입니다.

  1. 윈도우의 SSDP 서비스가 꺼져 있음 — r6upnp.bat 이 알아서 켜고 다시 시도합니다. service SSDPSRV started 가 보이면 그 다음 줄들을 보세요.
  2. 공유기에서 UPnP 가 꺼져 있음 — 이건 손으로 열어야 합니다. 대부분 여기입니다.

검은 창에 아무것도 안 뜨고 멈춰 있으면 — 창 제목을 보세요. "선택" 이 붙어 있으면 창 안을 클릭한 것입니다. 윈도우는 글자가 선택된 동안 출력을 멈춥니다. Esc 를 누르면 이어서 나옵니다. (공유기에 물어보는 데 20초쯤 걸립니다 · 그동안은 그냥 기다려주세요)

손으로 여는 방법은 r6upnp.bat 이 내 실제 주소를 넣어서 화면에 찍어줍니다. 그대로 따라 하시면 됩니다.

  1. 브라우저에 화면에 찍힌 router 주소를 칩니다
  2. 먼저 WAN(인터넷) 주소부터 확인하세요. 위쪽 내 접속 주소와 같아야 합니다. 10. · 172. · 192.168. 로 시작하는 다른 사설 주소가 찍혀 있으면 공유기가 두 겹이라 여기서 포트를 열어도 소용없습니다 → Radmin 으로 가세요.
  3. 로그인 후 포트 포워딩을 찾습니다 — 공유기마다 NAT, 가상 서버, 포트포워드 로도 부릅니다
  4. 규칙 셋을 넣습니다. 화면에 찍힌 this PC 주소로 보냅니다.
    • UDP 2346 → 내 PC
    • UDP 2347 → 내 PC
    • UDP 2348 → 내 PC
  5. 들어간 김에 UPnP 항목이 있으면 켜두세요. 다음부터는 r6upnp.bat 이 알아서 합니다.

포트 포워딩 메뉴를 못 찾겠으면 DMZ 칸에 내 PC 주소를 넣어도 됩니다. 한 줄로 끝나지만 그 PC의 모든 문이 열립니다 — 편한 만큼 덜 안전합니다.

공유기를 못 건드리는 환경(회사·기숙사·공유 인터넷)이면 방장을 할 수 없습니다. 접속 방식을 Radmin 으로 바꾸면 공유기와 무관하게 됩니다. 방장 한 명만 바꾸면 되는 게 아니라, 그 방에 들어올 사람 모두 Radmin 을 켜야 합니다.

게임 안에서 맞춰둘 설정 — MULTIPLAYER OPTIONS

게임 › MULTIPLAYER › MULTIPLAYER OPTIONS 에서 아래처럼 맞춰주세요. 회원 모두 같은 값이어야 서로를 찾습니다.

  • ANNOUNCE SERVER 해제 — 꺼두세요. 켜두면 방이 모두의 JOIN GAME 목록에 떠서, 런쳐를 거치지 않고도 아무나 들어옵니다. 끄면 주소를 아는 사람만 들어올 수 있고, 그 주소는 사이트에서 같은 방에 들어와 있는 사람에게만 보입니다
  • INTERNET / LAN LAN — Radmin 이 랜처럼 이어주므로 LAN 이 더 빠릅니다. 이 값은 게임이 응답을 얼마나 참고 기다릴지를 정합니다 — INTERNET 은 느린 회선을 가정해 한참 기다립니다.
  • INTERNET / LAN INTERNET — 공인 IP 로 곧장 붙는 방식이라 INTERNET 이 맞습니다.
  • BEHIND FIREWALL NO — YES 로 두면 느려집니다. 대신 아래 포트를 열어주세요
  • JOIN PORT 2346 · ANNOUNCE PORT 2347 · INFO PORT 2348 — 기본값 그대로
  • SERVER NAME 방 번호를 넣어서 — 예: 1번방 LOTUS_TeaRs. ANNOUNCE 를 껐어도 방 안에서는 이 이름이 보입니다
  • PLAYER NAME 사이트 아이디와 같게 — 누가 누군지 바로 보입니다

ANNOUNCE SERVER 를 끄면 JOIN GAME 목록에 아무것도 안 뜨는 것이 정상입니다. 그게 목적입니다 — 런쳐가 알려주는 주소로만 들어오게 하려는 것입니다. 참가자는 런쳐가 알아서 그 주소로 붙여줍니다.

그래도 목록에서 들어오게 하고 싶다면 ANNOUNCE 를 켜두시면 됩니다. 다만 여러 방이 동시에 열리면 목록에 다 떠서 엉뚱한 방에 들어가는 일이 생깁니다.

접속이 오래 걸릴 때 — 방화벽 열기

게임은 접속할 때 상대의 포트 세 개를 두드려 봅니다 — 2346(JOIN) · 2347(ANNOUNCE) · 2348(INFO). 막혀 있는 포트가 있으면 "응답 없음"으로 판정될 때까지 기다렸다가 다음을 시도합니다. 그 기다림이 쌓여 접속이 느려집니다.

  1. r6firewall.bat 내려받기
  2. 오른쪽 클릭 → 관리자 권한으로 실행
  3. 방장과 참가자 모두 한 번씩 해야 효과가 있습니다
  4. 게임 허용 · UDP 세 포트 · 핑 응답, 이 세 가지를 엽니다

JOIN 누르고 5초쯤 멎는다면 대개 한 번 시간초과가 났다가 다시 건 것입니다. 첫 패킷이 그냥 사라졌다는 뜻이라, 원인은 둘 중 하나입니다.

  1. 포트가 막혀 있다 — 위 파일로 해결됩니다
  2. Radmin 길이 아직 안 뚫려 있다 — Radmin VPN 의 길은 처음 말을 걸 때 만들어집니다. 게임이 그 첫 손님이 되면 게임이 그 시간을 다 기다립니다. 런처가 게임을 켜기 전에 미리 두드려 둡니다 — r6launch.bat 이 하는 일입니다.

직접 재보려면 시작 › cmd 를 열고 ping -n 10 방장주소 를 쳐보세요 (예: ping -n 10 26.131.188.239). 첫 줄만 느리고 나머지가 빠르면 위 2번이 맞습니다. 계속 느리거나 손실이 나면 Radmin 연결 자체를 봐야 합니다.

그래도 느리면 MULTIPLAYER OPTIONS 에서 INTERNET / LAN 을 바꿔가며 재보세요. Radmin 은 랜처럼 보이지만 실제로는 인터넷을 타기 때문에, INTERNET 쪽이 더 나을 수 있습니다. BEHIND FIREWALL 은 NO 여야 합니다 — YES 는 일부러 느리게 도는 설정입니다.

메모장으로 열면 무엇을 하는지 다 보입니다. 게임 허용과 UDP 세 포트를 여는 것이 전부이고, 되돌리는 명령도 적혀 있습니다.

로그인하면 방에 들어갈 수 있습니다.
